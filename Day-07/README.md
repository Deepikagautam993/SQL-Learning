# DAY 07 - WINDOW FUNCTIONS IN SQL

## Overview

In Day 07, advanced SQL Window Functions were covered. These functions are heavily used in Data Analytics, Dashboard Reporting, KPI Systems, Financial Analysis, and Business Intelligence projects.

Window Functions allow analytical calculations without collapsing rows, which makes them different from `GROUP BY`.

# Important Concepts Learned

## OVER()
Defines the calculation window for analytical functions.

## PARTITION BY
Creates logical groups for calculations while keeping rows visible.

## ORDER BY
Controls calculation sequence inside window functions.

## ROW_NUMBER()
Assigns unique sequence numbers to rows.

## RANK()
Assigns same ranks to duplicate values and skips positions.

## DENSE_RANK()
Assigns same ranks to duplicate values without skipping positions.

## LEAD()
Accesses next row values for future comparison.

## LAG()
Accesses previous row values for trend analysis.
