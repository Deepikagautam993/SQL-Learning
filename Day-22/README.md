# 🚀 Day 22 - Normalization in PostgreSQL

## 📌 Overview

Welcome to Day 22 of the PostgreSQL Learning Journey.

This module focuses on **Database Normalization**, one of the most important concepts in database design. Normalization helps reduce data redundancy, improve data consistency, and create efficient database structures.

By the end of this day, you will understand how to organize data properly using different normal forms and design scalable databases.

---

## 🎯 Learning Objectives

After completing this module, you will be able to:

- Understand the purpose of Normalization
- Identify Functional Dependencies
- Apply First Normal Form (1NF)
- Apply Second Normal Form (2NF)
- Apply Third Normal Form (3NF)
- Apply Boyce-Codd Normal Form (BCNF)
- Understand Denormalization concepts
- Design efficient database schemas
- Reduce data redundancy and anomalies
- Build normalized real-world database structures

## 📊 Normal Forms Summary

| Normal Form | Purpose |
|------------|----------|
| 1NF | Remove Repeating Groups |
| 2NF | Remove Partial Dependency |
| 3NF | Remove Transitive Dependency |
| BCNF | Ensure Every Determinant is a Candidate Key |
